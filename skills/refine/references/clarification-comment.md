# Clarification comment format

One comment, addressed to the people who can decide. Plain words, short sentences. No greeting or thanks.

## Questions

Rank by what blocks most. Merge questions that one answer settles. Aim for five or fewer; if more remain, say which can wait until after planning. Ask one thing per question.

1. **Question.** A concrete example from this project that shows the choice. *Proposed:* the answer the evidence supports, if any; note when it reverses a recorded decision.

## What happens today

After the questions: at most four bullets of current behavior that the questions depend on, each with a file or doc reference. Name any recorded decision the request would change.

## After the answers

One sentence: what will be drafted next (requirements and acceptance examples), and which answers are needed before planning can start.
